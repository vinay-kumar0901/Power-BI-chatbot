# BI-GPT usage

Ask questions such as:
- Explain the DAX measure named [measure name].
- Which tables and relationships are in this model?
- Which report pages and visuals exist?
- Explain the fact and dimension tables.
- What is the numerator and denominator of the selected KPI? (Requires a documented definition.)
- Calculate the number of records in [table].
- Show monthly totals using [date column] and [numeric column].

The assistant must distinguish metadata explanations from calculations based on imported rows.
